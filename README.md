# 数字当てカード（実物カードのスマホ代替）

1〜60 の数字当てカード6枚を、そのままスマホで見せるためのアプリ。
**アプリは数字を当てない。** YES / NO の入力も、記録も、結果表示も一切ない。
当てるのはあなた。アプリはカードを見せるだけ。

## 遊び方

1. 相手にスマホを渡す
2. 「1〜60 の中から好きな数字をひとつ決めて」
3. START → カードを1枚ずつ見せる（画面タップでめくる）
4. 「ある」と言われたカードの**左上の数字**を頭の中で足す
5. 6枚目の次に「あなたの思い浮かべた数字は…」が出る。
   スマホを返してもらって、あなたが数字を言う

左上の数字がそのカードの重み（1 / 2 / 4 / 8 / 16 / 32）なので、
カードの見た目だけで何を足せばいいか分かる。覚える必要はない。

例：「ある / ない / ある / ない / ない / ある」→ 1 + 4 + 32 = **37**

## 操作

| 操作 | 動き |
| --- | --- |
| 画面のどこかをタップ | 次のカードへ |
| 画面**左端**から右へスワイプ | 前のカードへ戻る（誤タップ用。目立たせていない） |
| 最後の画面の「もう一度」 | 最初から |

最後の「あなたの思い浮かべた数字は…」の画面ではタップでは進まない。
「もう一度」を押したときだけ戻る。スマホを返してもらうときに暴発しないようにするため。

## 色のギミック（ミスディレクション）

奇数枚目のカード（1 / 4 / 16）は一部の数字が**赤**、
偶数枚目のカード（2 / 8 / 32）は一部の数字が**緑**になっている。

**この色に意味はない。** 相手に「色が手がかりなんじゃないか」と考えさせるためだけの飾り。

その代わり、飾りとして破綻しないよう次を守っている（`verify.mjs` で検証済み）。

- 色は固定ハッシュで決まるので、**何度見せても同じ配色**。実物のカードと同じように矛盾しない
- 各カードちょうど7個。数を数えても法則が見えない
- **左上の数字（＝あなたが読む重み）には絶対に色をつけない**。色と答えが結びつく余地をなくすため
- どの数字も「色がついていないカード」を最低1枚は持つ。
  「この数字はいつも赤」のような単純な法則に見えないようにしている

## 動かし方

Node.js が入っている前提。

```bash
cd number-cards
npm install
npx expo start
```

表示された QR コードをスマホの **Expo Go** アプリ（App Store / Google Play で無料）で読むと、そのまま実機で動く。

ホーム画面に置けるアプリとして書き出したい場合：

```bash
npx expo run:ios      # macOS + Xcode が必要
npx expo run:android  # Android Studio が必要
```

または EAS Build（`npx eas build -p ios --profile development`）でクラウドビルドする。

## 中身

| ファイル | 役割 |
| --- | --- |
| `cards.js` | 6枚のカードの中身を**ビット演算で自動生成**（数字のハードコードなし）＋ 色のギミック |
| `App.js` | 画面と操作のすべて |
| `verify.mjs` | 6枚で 1〜60 が一意に表現できるかの検証スクリプト |

検証は `node verify.mjs` で実行できる。

- 全 2^6 通りの YES/NO パターンから復元した数字が 1〜60 を過不足なく覆い、重複しないこと
- 各数字について「その数字が載っているカードの重みの合計＝その数字」であること
- 色のギミックが答えと無相関で、単純な法則には見えないこと

を機械的に確かめている。

## カードの数字を変えたいとき

`cards.js` の `MAX_NUMBER` を変えるだけ。
たとえば `63` にすれば 6枚のまま 1〜63 に、`31` にして `BITS` から `32` を消せば 5枚で 1〜31 になる。
グリッドの行数（`ROWS`）も文字サイズも自動で追従する。

`COLUMNS` は1行あたりの数字の個数。少なくすると数字が大きくなる（初期値 4）。
`ACCENT_PER_CARD` は色をつける個数（初期値 7）、`ACCENT_COLORS` は赤と緑の色コード。

## 設計メモ

- 結果を計算する関数はアプリ内に**存在しない**。手品の答えはコードのどこにも出てこない
- 進捗表示（1 / 6 など）は出さない。実物のカードに進捗表示はないため
- 画面遷移は「右から次のカードが差し込まれる」だけ。派手な演出はしない
- ステータスバーは非表示、向きは縦固定
- 端末がスリープすると手品が途切れるので、気になる場合は `npx expo install expo-keep-awake` して
  `App.js` で `useKeepAwake()` を呼ぶとよい
